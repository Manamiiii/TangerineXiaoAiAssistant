# 0.3.0 桌面版

完整解压便携包，双击 `TangerineXiaoAiAssistant-Desktop.exe`。首次打开自动建立默认配置；不会自动登录或开启开机自启。

## 使用

1. 在“连接与设置”点击“扫码登录小米”，用米家 App 扫码、在手机上确认。二维码只在窗口内存中显示，不落盘。
2. 选择音箱，点击“保存设置”。账号已保存时，可以直接刷新音箱。
3. 点击“检查连接”，成功时显示对话记录数量，不执行历史命令。
4. 点击“开始监听”，等状态变为“正在监听，可以说指令”，再说“让电脑打开 B 站”。

“语音命令”可以添加固定网页、登记已安装的 EXE、移除规则，或为旧配置补入音量和锁屏。这里的修改暂存于窗口，需返回“连接与设置”保存；监听使用磁盘中已保存的配置。更复杂的别名仍可编辑 JSON。

监听时先点“停止 / 取消”，等停止后才能保存、登录或修改命令。停止不会撤销已经完成的电脑动作。当前网络请求返回时会检查停止标记，避免继续处理返回的语音。退出需等待正在进行的网络请求结束，网络异常时可能需要几十秒。

关闭窗口和“收起到托盘”都保留程序；点击通知区域的橘子图标可重新打开。托盘右键有开始、停止、退出菜单。要彻底停止程序，请用“退出助手”或托盘“退出”。桌面版和 CLI 共用单实例锁，使用 `login.cmd` 等命令行工具前先退出桌面版。

## 开机自启

默认关闭。勾选“登录 Windows 后自动启动并监听”，再保存才会启用。仅写当前 Windows 用户的 Run 注册表项，不需要管理员权限，不安装系统服务。取消勾选并保存会删除本程序的启动项，不改其他软件。

请把便携包完整放到固定目录后再启用。移动目录或升级到另一目录后，使用新目录内的程序重新保存自启设置；删除程序前建议先关闭自启。开机启动会收起到托盘并使用已保存配置开始监听；手动双击打开时显示设置，需自己点击开始。自启时尚无配置/登录/音箱，会显示提示，不执行任务。

注册表单元测试全部使用替身，没有为开发者机器启用自启。注销重登后的自动启动、Windows 10、不同缩放比例尚待现场验证。

## 实现与边界

- Tk 主线程负责窗口，pystray 在 Windows 工作线程负责托盘。官方支持该线程用法：[pystray 文档](https://pystray.readthedocs.io/en/latest/usage.html)。
- 一个串行工作线程负责登录、设备列表、探测或监听；事件队列把状态送回窗口。不会同时登录和监听。
- 复用原有 Xiaomi Adapter、DPAPI、白名单路由、去重和退避，不开放网络服务。
- 取消二维码登录后，不继续交换或保存新令牌；已完成并保存的登录不会因为随后取消设备列表请求而回滚。
- 托盘不可用时显示设置窗口，不能收起；退出释放锁后才能重新启动。
- 不需要 Qt、浏览器 GUI 自动化或管理员权限。未实现安装器、自动更新、真实 WorkBuddy 提交。
- 小米实际账号、音箱型号与固件兼容性仍需真机验证；界面测试不能代替扫码和语音测试。

## 依赖源码和重建

便携包的 `source/pystray-0.19.5.zip` 包含托盘库的完整对应源码；`source/TangerineXiaoAiAssistant-0.3.0-source.zip` 包含应用代码、测试和构建脚本。GPL/LGPL 许可证原文在 `licenses/runtime/pystray/`。本程序使用 pystray（Copyright 2016–2022 Moses Palmér），该库及对该库的使用受 LGPL-3.0-or-later 约束。

允许修改本程序中与该库结合的部分、为调试库修改进行逆向工程，并使用随附应用源码重建、重新组合和分发修改后的组合程序；第三方代码继续遵守各自许可。无需签名密钥或安装授权即可运行自行重建的 exe。

在 Windows 安装 Python 3.12 x64（包含 Tcl/Tk），解压应用源码，按 README“开发”步骤安装固定构建依赖并运行 `python scripts/build.py`。若要替换 pystray：解压它的源码，修改 `lib/pystray/` 后安装这个目录的项目（`python -m pip install --no-deps --no-build-isolation 路径`）；把修改后的源码目录重新压缩为 zip，保留顶层 `pystray-0.19.5/`，运行 `python scripts/build.py --pystray-source 修改后的源码.zip`。构建脚本会校验已安装库源码与提供的源码一致，并把它一起打入包。接口兼容的修改不受程序额外限制。
