# 第一次使用与排错

先看 [README 下载入口](../README.md)。当前公开包为 0.3.0；“窗口底部保存、未保存提示、演练所选、退出小米登录、自动配置备份”属于尚未发布的 0.3.1.dev0 改进。不要期待旧包已经具有这些功能。

## 从下载到第一次口令

1. 打开 Releases，展开 Assets，下载 `windows-x64.zip`。GitHub 代码目录没有 dist；Source code 不是运行包。
2. 右键 ZIP → 全部解压，进入文件夹，运行带 **-Desktop.exe** 的文件。不要在压缩包里直接运行。预期出现“连接与设置”窗口。
3. 点击“扫码登录小米”，使用绑定音箱的小米账号在米家 App 扫码并确认。不要向任何人发送二维码或凭据。
4. 下拉选择音箱，保存设置。0.3.0 保存按钮在连接页，本地改进版位于窗口底部。只有一个设备时会自动选中，但仍要保存。
5. 点击“检查连接”。显示记录数量只证明该请求成功；0 条不一定是错误，也不证明新语音可用。
6. 点击“开始监听”，等“正在监听，可以说指令”，对音箱说“小爱同学，让电脑打开 B 站”。预期浏览器打开一次固定网页，10 秒内不重复打开。
7. 停止并重新开始监听，预期不重放刚才的历史口令。最后使用“退出助手”退出。

第 3–7 步中的真实账号、音箱、网页结果和播报需要实际设备验收，目前没有已验证机型清单。如果你暂时没有设备，无需扫码；可先查看窗口和配置。

## 添加网页、应用与演练

在“语音命令”点击“添加网页”，输入要说的名称和固定 HTTP/HTTPS 网址。输入的名称会成为“打开名称”的口令。添加应用需要选择已经安装在这台电脑上的 EXE，再输入名称；程序不替你安装微信等软件，不接受快捷方式或脚本。

先停止监听再修改，修改后保存、重新开始。改进版各页都有保存按钮和未保存提示；开始监听/检查连接前会询问是否保存，保存失败则不会悄悄使用旧配置。删除命令只删除规则，不删除应用文件；真正生效前需要保存。

改进版可选中一条命令，点击“演练所选”：只验证示例能否匹配唯一规则，不执行动作，不联网，不验证音箱识别。锁屏、音量也可以安全演练。要测试实际效果，需单独说出真实口令。

更复杂的别名可以在退出程序后编辑 `config.json`，格式见 [config.example.json](../config.example.json)。保留默认数据结构；不要在配置中填写密码、Token 或命令行参数。

## 根据现象排错

| 现象 | 先做什么 | 成功时应看到什么 |
|---|---|---|
| 二维码申请失败、连接超时 | 检查电脑联网和代理后重试；二维码过期重新申请 | 出现可扫码图片，再在手机确认 |
| 安全连接验证失败 | 检查系统时间与网络，不要关闭证书验证 | 请求恢复正常 |
| 登录保存成功但设备列表失败 | 点“刷新音箱”；不用立刻重新扫码 | 出现设备列表 |
| 音箱列表为空 | 确认账号归属、设备在线；共享设备和地区兼容性尚未验证 | 列表出现可选择设备；否则记录型号反馈 |
| 所选音箱不在当前账号中 | 刷新、重新选择、保存，然后检查连接 | 对话接口返回数量 |
| 列表中有音箱但对话接口不支持 | 核对设备选择；仍失败时反馈型号和固定错误提示 | 只有接口通过后才进行语音测试 |
| 开始监听没反应 | 等初始化完成；按命令表说完整口令，别遗漏触发词 | 日志出现匹配结果；不要求日志显示语音全文 |
| 收到命令却没打开应用 | 重新登记当前安装目录的 EXE；仅支持无额外参数启动 | 日志显示已请求启动，应用实际出现需现场确认 |
| 音量调了仍没声音 | 检查 Windows 是否静音、默认播放设备是否正确 | 数值改变但静音状态保留，这是预期行为 |
| 退出暂时没结束 | 等正在进行的网络请求返回，异常网络可能需几十秒 | 托盘消失，之后可重新启动 |

## 配置恢复、升级与卸载

数据目录是 `%LOCALAPPDATA%\TangerineXiaoAiAssistant`。可以在“运行日志”打开目录，也可把路径粘贴到资源管理器地址栏。这里可能含有私有配置和加密凭据，不要整体上传。

改进版每次更改有效配置时，保留一份上次的 `config.json.bak`。需要恢复时先退出助手，把当前 `config.json` 移到你自己的备份位置，再复制 `config.json.bak` 为 `config.json`。原始配置损坏时不会自动重置；文件被外部编辑后，窗口保存会拒绝覆盖并提示重新打开。备份只保留上一个版本，不是完整历史。

如果没有可用备份：先退出助手，将损坏的 `config.json` 单独保留到别处，再打开桌面版，会重新生成默认规则。已有加密登录不会因此删除，但需要重新选择音箱；自定义命令需自行恢复。

升级：退出旧程序 → 完整解压新包 → 打开新 Desktop.exe。默认使用原来的数据目录。不要将加密登录文件复制给其他 Windows 用户；换电脑重新登录。若已开启自启且程序目录变化，在新程序中重新保存自启设置。

卸载：取消自启并保存 → 退出小米登录 → 退出助手 → 删除解压目录。0.3.0 没有图形注销入口，可先退出桌面版，在该目录 PowerShell 运行 `TangerineXiaoAiAssistant.exe logout`。本地凭据删除不等于撤销小米云端会话；需要管理云端登录时使用小米账号的官方入口。

卸载程序不会自动删除配置和日志。若不再需要，确认退出后自行删除上述数据目录。不要把包含个人文件的上层 `%LOCALAPPDATA%` 目录整体删除。

## 反馈问题

在仓库 Issues 提供：程序版本、Windows 版本、小爱型号、失败步骤、界面固定提示，以及是否能通过“检查连接”。说明是实际设备测试还是本地演练。

不要发送密码、Token、二维码、完整网络响应、整个数据目录或未经检查的配置。先用固定错误提示反馈；确实需要日志时先自行审阅，删去个人信息。项目不提供专职支持或确定的修复时限。
