# 隐私、权限与安全边界

## 处理哪些数据

- 语音由小爱音箱和小米服务识别。助手经小米云端接口读取所选音箱最近的对话记录，再在本地匹配触发词；这可能包括没有触发助手的其他对话。
- 对话文本只在处理期间存在内存中，不由本程序保存语音录音或对话历史，不发送给大模型。小米如何处理语音取决于其服务和账号设置，本程序不能替代或控制它们。
- `config.json` 保存设备 ID、固定网址、应用路径及规则，可能包含个人信息。改进版的 `.bak` 也包含此前配置，应同样保护。
- `xiaomi.dpapi` 是当前 Windows 用户加密的小米会话令牌；不保存账号密码。加密不防御已经控制同一 Windows 用户的恶意软件。
- `assistant.log` 只写连接状态、固定错误和执行结果类型，不写 Token、密码、远端响应原文或语音全文；轮转文件总量约 1.5 MB。界面会本地显示音箱名称，但不写进日志。
- 桌面二维码只在内存中显示；CLI 登录临时保存 `login-qr.png`，正常退出后删除。强制终止或断电可能留下临时二维码，需要自行清理。

不包含广告、遥测、产品账号或远程控制服务器。不自动收集和上传故障报告。

## 权限与指令

不需要管理员权限。开机自启默认关闭，只在明确勾选并保存后修改当前用户的本程序启动项；不安装系统服务。

网页和应用目标来自你确认的本地配置，语音不能直接提供 URL、路径、Shell 或参数。默认锁屏、音量等口令可被音箱附近其他人说出；没有说话人身份验证，也不把音箱当作安全认证设备。不希望使用的命令可移除并保存。

本地配置不是防恶意软件的沙箱。不要从陌生人处导入未核对的规则或 EXE。助手也不能保证被打开网页的内容安全。

## 分发与依赖

下载便携包时核对项目仓库和 SHA256SUMS.txt。校验可检查文件是否一致，不能替代对作者或代码的信任。当前包未签名；不建议绕过 Windows 安全检测或关闭防护软件。

2026-10-30 对 18 个固定运行/构建依赖查询 OSV：旧 Pillow 12.3.0 命中安全公告，改进版更新到 13.0.0 后未返回版本匹配项。本项目不据此宣称没有漏洞，也没有证明全部公告能通过当前 PNG 二维码入口触发。二维码解码另外限制为 PNG、大小和尺寸上限。

参考：[Pillow 13.0.0 发布说明](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html)、[上游安全公告示例](https://github.com/python-pillow/Pillow/security/advisories/GHSA-24rc-8hj2-v98c)、[OSV 查询 API](https://google.github.io/osv.dev/post-v1-querybatch/)。已发布 0.3.0 包不会因本地源码修改而自动更新。

新构建使用独立临时目录，依据明确清单收集源码/文档，拒绝覆盖已有输出，避免把试用时留下的日志和凭据混入发布包。维护者仍需检查清单新增文件和压缩包内容。

发现疑似凭据泄露时，不要把原文贴到公开 Issue；先停止分享相关文件，并通过小米官方账号入口检查会话。需要联系维护者时，仅先描述问题类型，不发送秘密。项目目前没有专用私密漏洞提交通道。
