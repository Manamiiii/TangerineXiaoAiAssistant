日期：2026-10-30（Asia/Shanghai）。审查基线：main `a10110e` / 0.3.0。原审查阶段改动仅在本地工作树，版本标为 `0.3.1.dev0`；当时不提交、不推送、不创建 Release、不改线上设置。

## 1. 定位、用户与成熟度

这是把小爱音箱已有的语音识别结果转为 Windows 固定操作的小工具。最合适的人是已经拥有小爱音箱和 Windows 电脑、愿意试用固定口令、偶尔希望离开键鼠操作的人；不适合期待自由聊天、无人值守关键任务、完全离线运行或承诺全型号兼容的人。

三个真实价值：

1. 常用网页/应用、音量、锁屏可用固定口令发起，降低离开键鼠时的操作成本；坐在桌前时未必比快捷键更快。
2. 简单命令由确定规则处理，无需模型调用或搭建智能家居平台；接口仍依赖小米云，不能宣传为纯离线。
3. Windows 便携程序带托盘和配置窗口，不需要安装 Python、额外工具账号或管理员权限；凭据本地加密，没有额外遥测或远程控制端口。

定位建议：**公开源码、面向小范围试用的个人工具 / 技术测试项目**。产品潜力明确，但真实音箱主链路未验收，原审查时项目自身通用许可证也未选定（现已在本地补齐），目前不宜直接宣称“成熟开源产品”“安装即用”或扩大推广。比纯个人脚本更完整，距面向陌生用户的稳定工具仍缺设备证据。

## 3. 优先级与本轮实施

### P0：先处理安全、数据与误导

- **依赖公告匹配，已修复本地版本**：18 个运行/构建锁定依赖查询 OSV，旧 Pillow 12.3.0 命中公告（如 GHSA-24rc-8hj2-v98c）。改为 13.0.0，二维码只交给 PNG 解码器。升级后同组查询无版本匹配项。不等于无漏洞，也未证实所有相关格式漏洞能经本程序触发。参考 [上游公告](https://github.com/python-pillow/Pillow/security/advisories/GHSA-24rc-8hj2-v98c) 和 [13.0.0 发布说明](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html)。
- **构建污染风险，已修复**：独立临时目录、显式 source-files 清单、拒绝覆盖已有输出；源码归档同样受清单约束。测试验证未审查文件不会入包，已有输出内的模拟凭据原样保留且构建拒绝继续。未发现旧公开包实际泄露凭据的证据。
- **配置丢失防护，已修复**：唯一临时文件、原子替换、上一版有效配置备份、GUI 保存前核对原始快照；失败不覆盖原配置。不能与任意外部编辑器实现跨进程事务，建议编辑 JSON 前先退出。
- **核心可用性声明，已澄清**：所有展示均标注测试版、待真机验证；WorkBuddy 不列为可用卖点。真机验收不是这轮代码检查可替代的工作。

### P1：降低试用与恢复成本

- 全局保存按钮、未保存状态；开始前提示保存、失败不启动，退出可取消或放弃更改；移除规则前确认。
- 空音箱列表给出归属/刷新指引，清除失效选择；登录已保存但列表失败时提示直接刷新。
- 网络、超时、安全连接错误使用固定且可操作的提示，不显示远端异常原文；隐藏窗口的授权/设备错误会打开设置。
- 新增安全的规则演练、图形退出小米登录；日志给出固定中文结果解释，保留机器结果码。
- README 第一屏说明用途、真实限制和明确下载入口；去掉开发者专属磁盘路径；补新手排错、升级、卸载、隐私、反馈模板。
- **已由作者决策并补齐（2026-11-03）**：原创代码采用 GPL-3.0-only，保留各第三方许可；[GitHub 官方说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) 也区分公开仓库与开放授权。

审查了全部版本控制文件：文档/示例/项目配置、应用和三个 vendored 协议模块、现有测试、入口与构建脚本、第三方许可；没有把 .venv、build、dist、research 的临时内容当成项目源码。

- 73 项单元/回归测试通过（原 59 项 + 14 项产品体验测试）。覆盖取消、去重、安全匹配、DPAPI、单实例，以及新增备份/磁盘替换失败/外部编辑冲突/损坏配置拒绝覆盖/未保存流程/空设备/登录部分成功恢复/PNG 格式与尺寸边界/打包清单与输出保护。
- `pip check` 通过。18 个锁定依赖升级后 OSV 查询无匹配公告；数据库核验有时间和覆盖范围限制。
- 对本地全部 4 个 Git 提交、77 个唯一历史 blob 做高置信 Token/私钥/长凭据模式扫描，未发现候选；这是有限规则检查，不是完整秘密检测或安全认证。
- 实际 Windows 窗口检查：全局保存、命令演练、未保存提示、保存反馈；未执行锁屏、未变更系统音量、未为本机开启自启，也未扫码。

成品构建、无 Python PATH 的 CLI/桌面运行、只读音量与中文/空格解压路径检查均通过，具体结果见 [VALIDATION.md](VALIDATION.md)。旧 Releases 仍是 0.3.0，本轮没有上传新包。

仍未验证：小米真实账号风控、目标音箱识别/记录与 TTS、网页在目标机加载结果、长时断网/休眠恢复、Windows 10、不同 DPI、注销重登自启和真实 WorkBuddy OAuth/任务。
